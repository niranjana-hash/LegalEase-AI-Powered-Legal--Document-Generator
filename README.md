LegalEase

AI-Powered Legal Document Assistant

LegalEase is an AI-powered application designed to help users understand legal documents in simple language. It can analyze legal documents, summarize important points, identify key clauses, and answer questions related to the uploaded document.

Features

- 📄 Upload legal documents
- 🤖 AI-powered document analysis
- 📝 Generate simple-language summaries
- 🔍 Identify important clauses and information
- 💬 Ask questions about the document
- ⚖️ Provide general legal information
- 🔐 Secure document handling

Installation

1. Clone the repository

git clone https://github.com/your-username/LegalEase.git
cd LegalEase

2. Set up the backend

cd backend
python -m venv venv

Activate the virtual environment.

Windows:

venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt

3. Configure environment variables

Create a ".env" file in the backend folder:

OPENAI_API_KEY=your_api_key_here

Never upload your real API key to GitHub.

4. Start the backend

uvicorn main:app --reload

5. Start the frontend

Open another terminal:

cd frontend
npm install
npm start

The application should now be available through your local development server.

How It Works

1. User uploads a legal document.
2. LegalEase extracts the document content.
3. The AI analyzes the content.
4. Important information and clauses are identified.
5. The document is summarized in simple language.
6. Users can ask questions about the uploaded document.
